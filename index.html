Bảng Nguyên hàm cơ bản & mở rộng (ax + b)

• ∫ k dx = kx + C
• ∫ xα dx = xα+1/(α+1) + C (α ≠ −1)
• ∫ (1/x) dx = ln|x| + C
• ∫ (1/x²) dx = −1/x + C
• ∫ (1/√x) dx = 2√x + C
• ∫ √x dx = (2/3)x√x + C
• ∫ ex dx = ex + C · ∫ ax dx = ax/ln a + C
• ∫ sin x dx = −cos x + C · ∫ cos x dx = sin x + C
• ∫ (1/cos²x) dx = tan x + C · ∫ (1/sin²x) dx = −cot x + C
• ∫ tan x dx = −ln|cos x| + C · ∫ cot x dx = ln|sin x| + C
• ∫ dx/(x²+k²) = (1/k)arctan(x/k) + C
• ∫ dx/(x²−a²) = (1/2a)ln|(x−a)/(x+a)| + C
Quy tắc mở rộng (ax + b): Thay x → ax + b thì nhân thêm hệ số 1/a phía trước (vd: ∫ sin(ax+b)dx = −(1/a)cos(ax+b) + C).

Tích phân & Ứng dụng hình học

• Newton–Leibniz: ∫ab f(x) dx = F(b) − F(a) · Từng phần: ∫ u dv = uv − ∫ v du
• Diện tích hình phẳng: S = ∫ab |f₁(x) − f₂(x)| dx
• Thể tích khối tròn xoay quanh Ox: V = π ∫ab |f₁²(x) − f₂²(x)| dx

Quy tắc tính Đạo hàm & Hàm hợp

• (u ± v)' = u' ± v' · (u·v)' = u'v + uv' · (u/v)' = (u'v − uv')/v² · (k/u)' = −ku'/u²
• Phân thức bậc nhất/bậc nhất: ((ax + b)/(cx + d))' = (ad − bc) / (cx + d)²
• Hàm hợp: y'x = y'u · u'x
• (C)' = 0 · (xα)' = αxα−1
• (√x)' = 1/(2√x) · (1/x)' = −1/x²
• (sin x)' = cos x · (cos x)' = −sin x
• (tan x)' = 1/cos²x · (cot x)' = −1/sin²x
• (ex)' = ex · (ax)' = ax ln a
• (ln x)' = 1/x · (logax)' = 1/(x ln a)

Giới hạn hữu hạn & Giới hạn vô cực

• limx→x₀ c = c · limx→x₀ x = x₀ · limx→±∞ c/xk = 0 (k ∈ ℕ*)
• limx→0⁺ 1/x = +∞ · limx→0⁻ 1/x = −∞ · limx→+∞ xk = +∞
• Khử dạng vô định 0/0: Phân tích nhân tử chung (x − x₀), nhân liên hợp, hoặc quy tắc L'Hôpital P'(x₀)/Q'(x₀).
• Khử dạng vô định ∞/∞: Chia cả tử và mẫu cho lũy thừa bậc cao nhất của x.

VCB Tương đương (khi u → 0) & Khai triển Maclaurin

• sin u ~ u · tan u ~ u · arcsin u ~ u
• 1 − cos u ~ u²/2 · eu − 1 ~ u
• ln(1 + u) ~ u · (1 + u)α − 1 ~ αu
• ex = 1 + x + x²/2! + x³/3! + o(x³)
• sin x = x − x³/6 + o(x³) · cos x = 1 − x²/2 + o(x²)
• limu→0 (1 + u)1/u = e

Hệ thức lượng trong Tam giác & Hình phẳng

• Δ vuông tại A (AH ⊥ BC): BC² = AB² + AC²; 1/AH² = 1/AB² + 1/AC²; AH² = BH·CH; AM = ½BC
• Δ đều cạnh a: Đường cao AH = a√3/2; Diện tích S = a²√3/4; Bán kính ngoại tiếp R = a√3/3
• Δ thường: S = ½ab sin C = √(p(p−a)(p−b)(p−c)) (Heron); a/sin A = 2R

Góc & Đường cao Hình Không Gian

• Góc đường thẳng & mặt phẳng: Góc giữa đường thẳng và hình chiếu vuông góc của nó lên mặt phẳng.
• Góc hai mặt phẳng: Từ chân đường cao hạ vuông góc xuống giao tuyến rồi nối lên đỉnh.
• Chóp có cạnh bên bằng nhau: Chân đường cao là tâm đường tròn ngoại tiếp đáy.
• Chóp có các mặt bên tạo đáy góc bằng nhau: Chân đường cao là tâm đường tròn nội tiếp đáy.

Tọa độ, Vectơ, Diện tích & Thể tích

• Trung điểm I = ((xA+xB)/2; ...) · Trọng tâm ΔABC: G = ((xA+xB+xC)/3; ...) · Tứ diện: chia 4
• Tích vô hướng: a⃗·b⃗ = a₁b₁ + a₂b₂ + a₃b₃ · Vuông góc ⇔ a⃗·b⃗ = 0
• Diện tích ΔABC = ½|[AB⃗, AC⃗]| · Thể tích tứ diện ABCD = ⅙|[AB⃗, AC⃗]·AD⃗|

Mặt phẳng, Đường thẳng, Mặt cầu & 4 Công thức Khoảng cách

• Mặt phẳng (P): A(x−x₀)+B(y−y₀)+C(z−z₀) = 0 · Đoạn chắn: x/a + y/b + z/c = 1
• Mặt cầu (S): (x−a)²+(y−b)²+(z−c)² = R² · R = √(a²+b²+c²−d) · Cắt (P): r = √(R²−d²)
• d(M, (P)) = |Ax₀+By₀+Cz₀+D| / √(A²+B²+C²) · d((P),(Q) //) = |D₁−D₂| / √(A²+B²+C²)
• d(M, d) = |[AM⃗, u⃗]| / |u⃗| · d(d₁, d₂ chéo nhau) = |[u₁⃗, u₂⃗]·A₁A₂⃗| / |[u₁⃗, u₂⃗]|

Phương trình bậc 2 & Hệ thức Vi-ét (Lớp 9)

• PT ax² + bx + c = 0 (a ≠ 0): Δ = b² − 4ac; Δ' = b'² − ac (b' = b/2).
• Hệ thức Vi-ét: S = x₁ + x₂ = −b/a ; P = x₁·x₂ = c/a.
• Biểu thức đối xứng hay gặp: x₁² + x₂² = S² − 2P ; x₁³ + x₂³ = S³ − 3SP ; |x₁ − x₂| = √(S² − 4P).

Bất đẳng thức kinh điển (AM-GM / Cauchy & Bunyakovsky)

• Cauchy (AM-GM): Với a, b ≥ 0: a + b ≥ 2√(ab) ; với a, b, c ≥ 0: a + b + c ≥ 3∛(abc).
• Bunyakovsky (Cauchy–Schwarz): (a₁² + a₂² + ... + aₙ²)(b₁² + b₂² + ... + bₙ²) ≥ (a₁b₁ + ... + aₙbₙ)².
• Cộng mẫu Engel (Schwarz): a₁²/x₁ + a₂²/x₂ ≥ (a₁ + a₂)² / (x₁ + x₂) (xᵢ > 0).

Lượng giác · Cấp số · Xác suất Bayes · Tài chính

• sin²x + cos²x = 1 · cos2x = cos²x − sin²x = 2cos²x − 1 = 1 − 2sin²x · sin2x = 2sinx cosx.
• CSC: uₙ = u₁ + (n−1)d, Sₙ = n(u₁+uₙ)/2 · CSN: uₙ = u₁qⁿ⁻¹, Sₙ = u₁(1−qⁿ)/(1−q).
• Bayes: P(A|B) = P(A)·P(B|A) / P(B) · Lãi kép: A = P(1+r)ⁿ ; liên tục: A = Peʳᵗ.

Cấp 2 & Ôn thi Chuyên Toán Lớp 9

• Thales & Phân giác: DE ∥ BC ⇔ AD/AB = AE/AC · Phân giác AD: DB/DC = AB/AC.
• Menelaus (thẳng hàng): (DB/DC)·(EC/EA)·(FA/FB) = 1 · Ceva (đồng quy): tích bằng −1 (có hướng).
• Stewart: AD²·a = AB²·n + AC²·m − amn · Apollonius: mₐ² = (2b²+2c²−a²)/4.
• Phương tích: PA·PB = PC·PD = PT² = |PO² − R²| · Ptolemy: ABCD nội tiếp ⇔ AC·BD = AB·CD + AD·BC.
• Simson – Steiner: Hình chiếu (hoặc đối xứng) của M ∈ (ABC) lên 3 cạnh thẳng hàng (Steiner đi qua trực tâm H).
• Euler: H, G, O thẳng hàng (OH⃗ = 3OG⃗); đường tròn 9 điểm Euler tâm trung điểm OH, R₉ = R/2.

Cấp 3, HSG Tỉnh, VMO & Bổ sung

• Carnot: 3 đường vuông góc 3 cạnh đồng quy ⇔ (MB²−MC²)+(NC²−NA²)+(PA²−PB²) = 0.
• Đối trung (Symmedian) & Lemoine: Tiếp tuyến tại B, C cắt tại T ⇒ AT đối trung; DB/DC = AB²/AC².
• Miquel, Trục/Tâm đẳng phương, Monge–D'Alembert, Đường tròn Apollonius, Bổ đề Archimedes.
• Xạ ảnh VMO: Hàng điểm điều hòa (A,B;C,D)=−1, Tứ giác điều hòa, Pascal, Brianchon, Desargues, Pappus, Brokard, Con bướm (Butterfly), Feuerbach, Newton–Gauss, Mixtilinear, Casey.
• Mở rộng: Pitot (tứ giác ngoại tiếp: AB+CD = BC+DA), Brahmagupta, Napoleon, Morley, Van Aubel, Sawayama–Thébault.
