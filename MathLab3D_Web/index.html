Bảng Nguyên hàm cơ bản & mở rộng (ax + b)

• ∫ k dx = kx + C
• ∫ xα dx = xα+1/(α+1) + C (α ≠ −1)
• ∫ (1/x) dx = ln|x| + C
• ∫ (1/x²) dx = −1/x + C
• ∫ (1/√x) dx = 2√x + C
• ∫ √x dx = (2/3)x√x + C
• ∫ ex dx = ex + C · ∫ ax dx = ax/ln a + C
• ∫ sin x dx = −cos x + C · ∫ cos x dx = sin x + C
• ∫ (1/cos²x) dx = tan x + C · ∫ (1/sin²x) dx = −cot x + C
• ∫ tan x dx = −ln|cos x| + C · ∫ cot x dx = ln|sin x| + C
• ∫ dx/(x²+k²) = (1/k)arctan(x/k) + C
• ∫ dx/(x²−a²) = (1/2a)ln|(x−a)/(x+a)| + C
Quy tắc mở rộng (ax + b): Thay x → ax + b thì nhân thêm hệ số 1/a phía trước (vd: ∫ sin(ax+b)dx = −(1/a)cos(ax+b) + C).

Tích phân & Ứng dụng hình học

• Newton–Leibniz: ∫ab f(x) dx = F(b) − F(a) · Từng phần: ∫ u dv = uv − ∫ v du
• Diện tích hình phẳng: S = ∫ab |f₁(x) − f₂(x)| dx
• Thể tích khối tròn xoay quanh Ox: V = π ∫ab |f₁²(x) − f₂²(x)| dx

Quy tắc tính Đạo hàm & Hàm hợp

• (u ± v)' = u' ± v' · (u·v)' = u'v + uv' · (u/v)' = (u'v − uv')/v² · (k/u)' = −ku'/u²
• Phân thức bậc nhất/bậc nhất: ((ax + b)/(cx + d))' = (ad − bc) / (cx + d)²
• Hàm hợp: y'x = y'u · u'x
• (C)' = 0 · (xα)' = αxα−1
• (√x)' = 1/(2√x) · (1/x)' = −1/x²
• (sin x)' = cos x · (cos x)' = −sin x
• (tan x)' = 1/cos²x · (cot x)' = −1/sin²x
• (ex)' = ex · (ax)' = ax ln a
• (ln x)' = 1/x · (logax)' = 1/(x ln a)

Giới hạn hữu hạn & Giới hạn vô cực

• limx→x₀ c = c · limx→x₀ x = x₀ · limx→±∞ c/xk = 0 (k ∈ ℕ*)
• limx→0⁺ 1/x = +∞ · limx→0⁻ 1/x = −∞ · limx→+∞ xk = +∞
• Khử dạng vô định 0/0: Phân tích nhân tử chung (x − x₀), nhân liên hợp, hoặc quy tắc L'Hôpital P'(x₀)/Q'(x₀).
• Khử dạng vô định ∞/∞: Chia cả tử và mẫu cho lũy thừa bậc cao nhất của x.

Hệ thức lượng trong Tam giác & Hình phẳng

• Δ vuông tại A (AH ⊥ BC): BC² = AB² + AC²; 1/AH² = 1/AB² + 1/AC²; AH² = BH·CH; AM = ½BC
• Δ đều cạnh a: Đường cao AH = a√3/2; Diện tích S = a²√3/4; Bán kính ngoại tiếp R = a√3/3
• Δ thường: S = ½ab sin C = √(p(p−a)(p−b)(p−c)) (Heron); a/sin A = 2R

Góc & Đường cao Hình Không Gian

• Góc đường thẳng & mặt phẳng: Góc giữa đường thẳng và hình chiếu vuông góc của nó lên mặt phẳng.
• Góc hai mặt phẳng: Từ chân đường cao hạ vuông góc xuống giao tuyến rồi nối lên đỉnh.
• Chóp có cạnh bên bằng nhau: Chân đường cao là tâm đường tròn ngoại tiếp đáy.
• Chóp có các mặt bên tạo đáy góc bằng nhau: Chân đường cao là tâm đường tròn nội tiếp đáy.
